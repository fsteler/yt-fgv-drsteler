Política de Privacidade

yt-fgv-drsteler · ferramenta pessoal do canal @drsteler

1. Escopo

Esta política vale para a ferramenta yt-fgv-drsteler, um script de uso pessoal que o dono do canal @drsteler roda no próprio computador. A ferramenta usa os Serviços de API do YouTube (YouTube API Services).

2. Dados acessados

Com a autorização do dono da conta, a ferramenta acessa a conta do YouTube dele pelos escopos youtube.force-ssl e youtube.upload. Ela lê a lista de vídeos e playlists do canal e grava vídeos, títulos, descrições, miniaturas, playlists e configurações de privacidade.

Ela não acessa dados de outras pessoas, como inscritos, comentários ou dados de outros canais.

3. Uso

Os dados servem só para gerenciar os vídeos do próprio canal, a pedido do dono. Não são usados para publicidade, perfilamento ou treinamento de modelos de inteligência artificial.

4. Armazenamento

O único dado guardado é o token de autorização do protocolo OAuth, em um arquivo local no computador do dono, com acesso restrito ao usuário do sistema. Não há servidor, banco de dados nem cópia em nuvem mantidos pela ferramenta.

5. Compartilhamento

Nenhum dado é vendido, cedido ou compartilhado com terceiros. As únicas chamadas de rede vão para as APIs do Google.

6. Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Revogado o acesso, o token local deixa de funcionar e pode ser apagado do computador.

7. Políticas do Google e do YouTube

Ao usar a ferramenta, o usuário concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

8. Contato

Pelo e-mail de suporte exibido na tela de consentimento do Google.
